# User Guide

Start the app with `python main.py`. A menu appears:

1.Add  2.Show  3.Complete  4.Delete  5.Exit

## 1. Add a task
Choose `1` and type a title, for example `Finish DevOps assignment`.
Empty titles are rejected with an error message.

## 2. Show tasks
Choose `2`. Completed tasks are marked with `[x]`, pending ones with `[ ]`.

## 3. Complete a task
Choose `3` and enter the task ID. You will see `Task completed.`
or `Task not found.`

## 4. Delete a task
Choose `4` and enter the task ID. An invalid ID shows `Invalid task ID.`

## 5. Exit
Choose `5` to quit.
